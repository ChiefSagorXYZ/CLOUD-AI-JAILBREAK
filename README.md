# CLOUDCODE — Claude Project Instruction Experiment

**Project type:** AI behavior and instruction-following experiment  
**Platform:** Claude Projects  
**Main instruction file:** `CLOUDCODE.txt`

## Overview

CLOUDCODE is an experimental project-instruction template for observing how persistent project-level instructions affect an AI assistant's response style, consistency, and task handling.

It is intended for controlled, harmless testing. It is **not** a verified jailbreak and does not guarantee that an AI system will follow every prompt or override its built-in safeguards.

## Setup

1. Sign in to [Claude](https://claude.ai/).
2. Open **Projects** and create a new project.
3. Open the project's **Instructions** section.
4. Open `CLOUDCODE.txt` from this repository.
5. Copy the complete contents of `CLOUDCODE.txt`.
6. Paste the text into the project's Instructions field and save.
7. Start a new conversation inside that project.
8. Try a harmless test prompt and observe the response.

## Suggested tests

- Ask for a short explanation of a general topic.
- Ask for a small, benign programming example.
- Ask for a creative-writing sample.
- Ask the assistant to summarize a short passage.
- Repeat the same prompt with and without the project instructions and compare the results.

## What to evaluate

Record whether the assistant:
- follows the requested response format;
- maintains a consistent tone;
- follows task-specific preferences;
- asks clarifying questions when needed;
- handles conflicting instructions appropriately.

## Limitations

- Project instructions are contextual guidance, not system-level controls.
- Model behavior can vary by model version, account settings, and product updates.
- The instructions cannot guarantee a particular response.
- Do not use this experiment to facilitate malware, credential theft, unauthorized access, or other harmful activity.
